n8n Automation & Webhook Integration

This automation suite is strictly restricted to administrators. Connect your n8n workflow HTTP Request nodes and external webhooks to these endpoints:

GET http://localhost:3000/api/properties

Search properties by combining query parameters: type, min_price, max_price, neighborhood, status.

curl "http://localhost:3000/api/properties?neighborhood=Downtown&type=Condo&max_price=1000000"
POST http://localhost:3000/api/bookings

Creates a new customer tour booking for an Austin property. Auto-generates unique BK-XXXX ID.

curl -X POST http://localhost:3000/api/bookings \ -H "Content-Type: application/json" \ -d '{"property_id":"HP-ATX-001","customer_name":"Alex Carter","customer_email":"alex@atx.com","customer_phone":"(512) 555-0199","booking_date":"2026-09-20","booking_time":"14:00","notes":"Interested in skyline views"}'

Full REST CRUD Endpoints for n8n

  • GET /api/properties/:id — Single property details
  • POST /api/properties — Create property listing
  • PUT /api/properties/:id — Update property specifications or status
  • DELETE /api/properties/:id — Delete property listing
  • GET /api/bookings?status=Pending — Fetch pending customer visits
  • PUT /api/bookings/:id — Confirm or cancel booking status
  • DELETE /api/bookings/:id — Remove booking
